INSTRUCTION HIERARCHY

指令的層級結構：越具體優先度越高

👥 人資招募自動化流程 (No-code / Low-code)

挑戰： 履歷過多，每份手動篩選耗時，且撰寫面試邀約信格式重複度高。

  • 步驟一： 在本地建一個 `resumes/` 資料夾，把所有 PDF/Word 履歷丟進去。
  • 步驟二： 建立 `JD.txt` 寫入評分條件（學歷、工作年資、關鍵技能）。
  • 步驟三： 執行 Cowork 自動比對並產生評分報告與邀約信草稿。
模仿實作 Prompt
"扮演行政人資顧問。讀取 resumes/ 的履歷，比對 JD.txt 條件。請為每人評分並寫出核心優缺點，整理成 outputs/評分表.xlsx。另外，請為 4分以上的候選人，以 Gmail 連接器起草邀約信存為草稿。"
【互動問答】在此案例中，學員需要自己動手寫 Python 程式碼來處理 Excel 報表產出嗎？
A. 需要，學員必須先學會編寫 Python 的 pandas 等大數據分析套件
B. 不需要！Claude 桌面版 (Run Code 功能) 會在背景自動編寫並執行程式，學員只需在 Prompt 指明輸出格式與欄位即可
C. 需要，並且必須在電腦中事先手動下載並設定好特定的資料庫
📈 業務績效管理與落後警示 (No-code / Low-code)

挑戰： 主管無法即時追蹤每位業務的成單率，等月底看財報往往已錯失時機。

  • 步驟一： 本地建立 `sales_data/` 資料夾，每日放入業務銷售記錄之 CSV 檔。
  • 步驟二： 設定 Global Instructions，表明業績落後警示標準（如：成單率 < 12%）。
  • 步驟三： 啟動 Cowork 批量讀取，自動找出落後項目，並為主管撰寫輔導信草稿。
模仿實作 Prompt
"扮演業務拓展顧問。讀取 sales_data/ 資料夾內近一週的銷售明細，計算每位業務的總成單量與平均成單率。若有業務的成單率低於 12%，請幫我列出名單，並為我（業務主管）起草一份績效輔導信件草稿，檔名命名為 outputs/績效輔導建議.docx。"
【互動問答】在業務績效分析中，如何確保 AI 篩選『成單率低於 12%』時，計算公式與結果百分之百精準？
A. 在 Prompt 或 `CLAUDE.md` 中給予明確的公式定義（例：成單率 = 成單量 / 總通話數）並指明數值標準
B. 相信 AI 自身的直覺分析，不需要額外給定計算公式
C. 必須先用試算表手動計算出結果後，再貼給 AI 核對
📍 網路行銷區域 (GEO) 成效分析 (No-code / Low-code)

挑戰： 各分店的 Google Maps 網路評論眾多且分散，難以跨地域比對並鎖定客訴店點。

  • 步驟一： 使用免程式碼網頁爬蟲工具，下載指定地區之分店 Google Maps 評價為 CSV 檔。
  • 步驟二： 將 CSV 檔案放入本地資料夾，讓 Cowork 自動讀取並依地理區域 (GEO) 分類。
  • 步驟三： 統計出平均星等與前三名客訴負面關鍵字（如：服務慢），自動輸出 Markdown 報告。
模仿實作 Prompt
"扮演行銷分析師。讀取資料夾內的 google_reviews.csv 評價資料，依據地理區域 (GEO) 欄位，計算各區店點的平均評分，並標示出評分低於 4.0 的店點。為這些低分店點歸納前三名的客訴負面關鍵字，並以 Markdown 格式表格輸出，存成 outputs/GEO分析.md。"
【互動問答】在網路行銷案例中，作為非程式人員的行銷人員，如何快速取得競爭對手或自家店點的評論 CSV 資料？

C. 使用 Apify、Web Scraper 等無程式碼 (No-code) 爬蟲工具，一鍵即可抓取整店 Google 評價並匯出 CSV
